# SpendWise – Smart Expense Tracker

SpendWise is an Android-based smart expense tracking application designed to help users manage their daily income and expenses in a simple and organized way.

The application is being developed as the Final Lab Project for the **Mobile Application and Development Lab (0613-410)**.

## Main Features

- Splash screen
- User registration and login
- Firebase Authentication
- Stay logged in / Remember Me
- Dashboard with balance, income, and expense summary
- Add income and expense transactions
- View transaction history
- Edit and delete transactions
- RecyclerView-based transaction list
- Firebase Realtime Database
- Input validation
- Receipt image using Camera or Gallery
- SharedPreferences for local settings
- Shake sensor for Quick Add Expense
- Share transaction details using Implicit Intent
- Material Design interface
- Snackbar and Toast messages

## How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Configure Firebase when Firebase integration is added.
5. Start an Android emulator or connect a physical Android device.
6. Wait until the device is fully booted.
7. Run the `app` configuration from Android Studio.
